SystemApiServer

業務支援システム データ配信API ドキュメント

`GET /read` は `table_name` クエリパラメータで読み取り対象を指定し、 `POST /read` は JSON 検索、`POST /update` は upsert を行います。どちらも対象テーブルは JSON の `table_name` で指定します。 API 公開対象テーブルは `sql/plango.sql` の DDL（`CREATE TABLE`）に基づく allowlist で管理されます。
