Excel Macro Friendly Guide

ソリューション製造部 業務支援システム データ配信API 利用ガイド

このAPIは、データベースのテーブル一覧取得、テーブルコメント取得、カラムコメント取得、データ検索、データ更新をHTTPで実行するためのものです。 このページは、Excelマクロから使う方を前提に、専門用語をできるだけ減らし、すぐ試せるVBAサンプル付きでまとめています。

最初に押さえる3点

  • 接続先の基本URLは通常 http://10.8.9.230:8810 です。
  • まずは show_tables でテーブル名を確認し、必要に応じてコメントAPIで意味を確認します。
  • 更新APIは「条件に合う1件目」を更新します。条件はできるだけ一意になるようにしてください。

APIの全体像

このAPIでできること

  • 利用可能なテーブル名の一覧取得
  • 利用可能なテーブルコメント、カラムコメントの一覧取得
  • 条件を指定してデータを検索
  • 条件に合うデータの更新、または新規作成

利用時の前提

  • リクエスト形式はJSONです。
  • 認証ヘッダーは実装上は必須ではありません。
  • レスポンスもJSONで返ります。
基本URL: http://10.8.9.230:8810 文字コード: UTF-8 Content-Type: application/json
初心者向けの安全な使い方
まずは show_tables でテーブル名を取得し、必要に応じて table/comments と table/column/comments で説明を確認し、 次に read で1件読んで列名を確認し、その後に update を使う流れがおすすめです。 特に update で使う values の列名は、実際のレスポンスに出てきた名前をそのまま使ってください。

用語をやさしく整理

用語 意味 例
table_name 対象テーブル名です。 ifs_projects_table
selector どのデータを探すかの条件です。 {"project_id":"1AS0006368"}
search_mode 条件をANDで見るか、ORで見るかです。 and_ / or_
values 更新したい列と値です。 {"status":"done"}
options 並び順や件数制限です。 {"order_by":"updated_at","limit":1}

エンドポイント一覧

GET

テーブル一覧取得

/system_api_server/si/v1/execute/script/show_tables

使えるテーブル名を一覧で返します。最初にここを呼ぶと、入力ミスを減らせます。

レスポンス例 
{
  "result": [
    "ifs_projects_table",
    "system_processes_table"
  ]
}
GET

テーブルコメント一覧取得

/system_api_server/si/v1/execute/script/show_tables/table/comments/

指定スキーマ内のテーブル名とテーブルコメントを一覧で返します。クエリ文字列の schema は省略時に ifs_reference_data が使われます。

項目 必須 内容
schema 任意 対象スキーマ名。省略時は ifs_reference_data
レスポンス例 
[
  {
    "TABLE_NAME": "ifs_projects_table",
    "TABLE_COMMENT": "案件マスタ"
  },
  {
    "TABLE_NAME": "system_processes_table",
    "TABLE_COMMENT": "システム処理マスタ"
  }
]
GET

カラムコメント一覧取得

/system_api_server/si/v1/execute/script/show_tables/table/column/comments/

指定スキーマ内のテーブル名、カラム名、カラムコメントを一覧で返します。列の意味を先に確認したいときに便利です。

項目 必須 内容
schema 任意 対象スキーマ名。省略時は ifs_reference_data
レスポンス例 
[
  {
    "TABLE_NAME": "ifs_projects_table",
    "COLUMN_NAME": "project_id",
    "COLUMN_COMMENT": "案件ID"
  },
  {
    "TABLE_NAME": "ifs_projects_table",
    "COLUMN_NAME": "project_name",
    "COLUMN_COMMENT": "案件名"
  }
]
POST

データ検索

/system_api_server/si/v1/execute/sql/read

条件に合うデータを配列で返します。0件でもエラーではなく、result: [] になります。

項目 必須 内容
table_name 必須 検索対象のテーブル名
selector 必須 検索条件。初心者向けには {...} の形式推奨
search_mode 任意 and_ または or_。省略時は or_
options 任意 件数制限や並び順。並び順は現在の実装では降順です
POST

データ更新または新規作成

/system_api_server/si/v1/execute/sql/update

条件に合うデータがあれば先頭1件を更新し、なければ新規作成します。 新規作成時だけ created_id に値が入る可能性があります。

項目 必須 内容
table_name 必須 更新対象テーブル名
selector 必須 どの行を更新するかの条件。新規作成も使うため、通常はオブジェクト形式推奨
values 必須 更新したい列と値
search_mode 任意 and_ または or_
DELETE

Delete one row

/system_api_server/si/v1/execute/sql/delete

`POST /update` と同じ selector 指定で一致した行を1件削除します。`values` は指定しません。

parameter required description
table_name required Delete target table name
selector required Condition object to identify the row to delete
search_mode optional and_ or or_
options optional Optional order_by and limit (delete executes as one-row delete)
values forbidden Not allowed for DELETE

検索のコツ

  • 完全一致にしたいときはそのまま指定します。例: {"project_id":"1AS0006368"}
  • 部分一致にしたいときは値に % を含めます。例: {"project_name":"%設備%"}
  • 更新APIは複数件ヒットしても先頭1件だけ更新します。条件は絞ってください。
  • まずは and_ を使うほうが事故が少ないです。

Excelマクロで始める手順

1

URLを決める

同じPC上でAPIを動かしているなら、基本URLは http://10.8.9.230:8810 です。別サーバーなら、そのホスト名またはIPに置き換えます。

2

VBAエディタを開く

Alt + F11 を押し、標準モジュールを1つ追加します。サンプルコードはそのまま貼り付けて使えます。

3

まず一覧取得

最初は show_tables を呼び、通信できているかを確認します。テーブルや列の意味を確認したい場合はコメント取得APIを先に使い、その後に検索、最後に更新へ進むのが安全です。

参照設定は不要です。
以下のサンプルは CreateObject("WinHttp.WinHttpRequest.5.1") を使っているため、VBAの参照設定を追加しなくても動かしやすい構成です。

VBAサンプル集

下のコードはそのまま標準モジュールに貼り付けて使えます。 まずはレスポンス文字列をシートに出すところから始めると理解しやすいです。

共通部品

標準モジュールの先頭に貼り付け 
Option Explicit

Private Const BASE_URL As String = "http://10.8.9.230:8810"

Private Function SendJsonRequest(ByVal httpMethod As String, ByVal path As String, Optional ByVal jsonBody As String = "") As String
    Dim http As Object
    Set http = CreateObject("WinHttp.WinHttpRequest.5.1")

    http.Open httpMethod, BASE_URL & path, False
    http.SetRequestHeader "Content-Type", "application/json; charset=utf-8"
    http.Send jsonBody

    If http.Status <> 200 Then
        Err.Raise vbObjectError + 513, "API Error", _
            "HTTP " & http.Status & vbCrLf & http.ResponseText
    End If

    SendJsonRequest = http.ResponseText
End Function

1. テーブル一覧を取得する

Sub SampleShowTables 
Sub SampleShowTables()
    Dim responseText As String

    responseText = SendJsonRequest( _
        "GET", _
        "/system_api_server/si/v1/execute/script/show_tables" _
    )

    Sheet1.Range("A1").Value = "テーブル一覧"
    Sheet1.Range("A2").Value = responseText
    MsgBox "取得完了: A2セルを確認してください。"
End Sub
まずこのマクロで通信確認をしてください。ここで失敗する場合、URLまたはAPIサーバー起動状態を確認します。

4. 1件読み取る

Sub SampleReadProject 
Sub SampleReadProject()
    Dim requestBody As String
    Dim responseText As String

    requestBody = Join(Array( _
        "{", _
        "  ""table_name"": ""ifs_projects_table"",", _
        "  ""search_mode"": ""and_"",", _
        "  ""selector"": {", _
        "    ""project_id"": ""1AS0006368""", _
        "  }", _
        "}" _
    ), vbCrLf)

    responseText = SendJsonRequest( _
        "POST", _
        "/system_api_server/si/v1/execute/sql/read", _
        requestBody _
    )

    Sheet1.Range("A4").Value = "検索結果"
    Sheet1.Range("A5").Value = responseText
    MsgBox "検索結果をA5セルに出力しました。"
End Sub
最初は responseText をそのままセルへ出して、どんな列名が返ってくるか確認するのがおすすめです。

5. 更新する

列名は実際のレスポンスを見て置き換えてください。

Sub SampleUpdateRow 
Sub SampleUpdateRow()
    Dim requestBody As String
    Dim responseText As String

    requestBody = Join(Array( _
        "{", _
        "  ""table_name"": ""ifs_projects_table"",", _
        "  ""search_mode"": ""and_"",", _
        "  ""selector"": {", _
        "    ""project_id"": ""1AS0006368""", _
        "  },", _
        "  ""values"": {", _
        "    ""your_column_name"": ""新しい値""", _
        "  }", _
        "}" _
    ), vbCrLf)

    responseText = SendJsonRequest( _
        "POST", _
        "/system_api_server/si/v1/execute/sql/update", _
        requestBody _
    )

    Sheet1.Range("A7").Value = "更新結果"
    Sheet1.Range("A8").Value = responseText
    MsgBox "更新結果をA8セルに出力しました。"
End Sub
重要: このAPIは条件に合った先頭1件を更新します。複数件ヒットする条件では意図しない更新になりやすいため、主キー相当の列で絞る運用を推奨します。

シートの値を使って検索する例

セルの値をそのまま検索条件に入れたいときの最小例です。

セル入力版 
Sub ReadBySheetValue()
    Dim projectId As String
    Dim requestBody As String
    Dim responseText As String

    projectId = Trim$(Sheet1.Range("B1").Value)
    projectId = Replace(projectId, """", "")

    If projectId = "" Then
        MsgBox "B1セルに project_id を入力してください。"
        Exit Sub
    End If

    requestBody = Join(Array( _
        "{", _
        "  ""table_name"": ""ifs_projects_table"",", _
        "  ""search_mode"": ""and_"",", _
        "  ""selector"": {", _
        "    ""project_id"": """ & projectId & """", _
        "  }", _
        "}" _
    ), vbCrLf)

    responseText = SendJsonRequest( _
        "POST", _
        "/system_api_server/si/v1/execute/sql/read", _
        requestBody _
    )

    Sheet1.Range("B3").Value = responseText
End Sub

JSONを表として扱いたい場合

Excel VBAには標準のJSONパーサーがないため、レスポンスを項目ごとに使いたい場合は VBA-JSON などのJSON解析モジュールを入れる方法が現実的です。 まずは上のサンプルで通信確認し、必要になった段階でJSON解析を追加してください。

VBA-JSON を使う場合のイメージ 
Sub ReadAndPutFirstRow()
    Dim responseText As String
    Dim json As Object
    Dim rows As Object
    Dim firstRow As Object

    responseText = SendJsonRequest( _
        "POST", _
        "/system_api_server/si/v1/execute/sql/read", _
        "{""table_name"":""ifs_projects_table"",""search_mode"":""and_"",""selector"":{""project_id"":""1AS0006368""}}" _
    )

    Set json = JsonConverter.ParseJson(responseText)
    Set rows = json("result")

    If rows.Count = 0 Then
        MsgBox "該当データがありません。"
        Exit Sub
    End If

    Set firstRow = rows(1)
    Sheet1.Range("D1").Value = firstRow("project_id")
    Sheet1.Range("D2").Value = firstRow("project_name")
End Sub

よくあるエラー

HTTPステータス 起きやすい原因 対応
400 存在しない列名を values に入れた。新規作成扱いなのに selector がオブジェクト形式でない。 まず read または table/column/comments で列名を確認し、同じ名前を使ってください。
404 table_name が存在しない。 show_tables の結果からコピペしてください。
500 DB接続設定、SQL実行失敗、内部例外。 APIサーバー側ログを確認してください。VBA側では ResponseText を残しておくと切り分けやすいです。
更新前の確認ポイント
1. 対象テーブル名は正しいか
2. 条件は1件に絞れているか
3. 列名はレスポンスで確認した綴りと一致しているか
4. 本番データなら、まず読み取りで対象行を確認したか

よくある質問

Q. 読み取りで0件でも正常ですか。

A. 正常です。レスポンスは {"result":[]} の形になります。

Q. 部分一致はできますか。

A. できます。値に % を含めてください。例: %設備%

Q. 複数件まとめて更新できますか。

A. 現在の実装では先頭1件更新です。複数件一括更新APIではありません。

Q. テーブルや列の意味を先に確認できますか。

A. できます。/show_tables/table/comments/ と /show_tables/table/column/comments/ でコメント一覧を取得してください。

このドキュメントの想定URLは http://10.8.9.230:8810、想定パスは /system_api_server/si/v1/execute/... です。利用環境が異なる場合は、基本URLだけ置き換えてください。
